# Data Sources

Use current sources whenever possible. Prefer direct evidence over broad trend claims.

## Primary Sources

| Source | What It Helps Answer | Notes |
|---|---|---|
| App Store product pages | Ratings, screenshots, positioning, reviews, IAP hints | Country-specific; use dates for reviews |
| Google Play product pages | Installs, ratings, reviews, screenshots | Install bands are useful demand proxies |
| Competitor websites | Pricing, positioning, platform support | Best source for subscription tiers |
| Changelogs/release notes | Product velocity, feature direction | Helps judge incumbent responsiveness |
| Product Hunt | Launch positioning and early adopter reaction | Upvotes are weak alone; comments help |
| GitHub | Open-source alternatives and developer demand | Stars are not revenue |
| Public docs/help centers | Feature depth and target workflows | Useful for B2B/SaaS-like apps |

## Secondary Sources

| Source | What It Helps Answer | Notes |
|---|---|---|
| Reddit | Raw complaints and unmet needs | Validate with other sources |
| Hacker News | Developer and prosumer pain | Can overrepresent technical users |
| YouTube/TikTok | Search behavior, tutorial demand, trend velocity | Watch for low-intent entertainment traffic |
| Google Trends | Relative interest over time | Not enough alone for small niches |
| Market reports | Macro category context | Often broad; avoid overfitting |
| Newsletters/forums | Indie maker revenue anecdotes | Treat as directional unless numbers are verified |

## Evidence Quality Labels

- **Strong:** Primary source, recent, directly tied to user behavior or pricing.
- **Medium:** Multiple independent secondary signals pointing to the same pain.
- **Weak:** Single anecdote, old report, vague trend claim, or unsourced estimate.

## Minimum Evidence For A Recommendation

For a top-ranked idea, include at least:

- 3 direct or adjacent competitors.
- 3 repeated pain patterns from reviews or discussions.
- 1 monetization signal.
- 1 distribution wedge.
- 1 clear MVP constraint that keeps the first build small.

# Roadmap

## v0.1

- Two-skill workflow: `app-opportunity-discoverer` and `app-opportunity-analyst`.
- Opportunity scoring rubric.
- From-scratch idea discovery, category analysis, idea validation, and opportunity ranking commands.
- Report templates.
- Example reports.
- Productized README with tagline, workflow diagram, quick start, and demo output previews.

## v0.2

- Add more realistic example reports with cited public sources.
- Add prompt tests for common categories.
- Add source-specific guides for App Store, Google Play, Product Hunt, Reddit, and Hacker News.
- Add a lightweight CLI wrapper.

## v0.3

- Add optional scripts for review clustering.
- Add CSV/JSON output format for opportunity scores.
- Add a local static report viewer.
- Add benchmark reports for 20 common indie app categories.
- Add automated public-source collection scripts.

## v1.0

- Stable workflow and rubric.
- Documented installation for Codex, Claude Code, Cursor, and other agent tools.
- Community-contributed reports and category playbooks.
- Clear open-core path for hosted monitoring and saved reports.
- Hosted web product exploration.

# Analyze App Category

Use the `app-opportunity-analyst` skill to analyze whether a specific app category is worth entering.

## Input

```text
Analyze category: <app category>
Platform: <iOS, Android, web, extension, cross-platform>
Goal: <traffic, subscription revenue, portfolio project, B2B leads>
```

## Instructions

1. Map the category into sub-niches and user jobs.
2. Gather current competitor evidence.
3. Compare pricing, ratings, review patterns, screenshots, onboarding, and feature depth.
4. Identify whether the category is growing, saturated, or fragmented.
5. Rank possible wedges by indie fit.
6. Give a go / validate / avoid recommendation.

## Output

Use `templates/opportunity-report.md`, but emphasize category-level conclusions.

## Example

```text
Analyze category: PDF scanner apps
Platform: iOS
Goal: subscription revenue
```
